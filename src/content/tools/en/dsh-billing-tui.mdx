## What it is

A billing plugin for DeepSeek Harness (DSH). It calculates a session's cost from DeepSeek's official peak and off-peak pricing, shows the running total in the TUI status line, and prints a persistent whale-themed ASCII receipt with `/billing`. It also supports the Web UI.

## Released and shared

- Published `dsh-billing-tui@0.1.0` on npm; installable with `dsh plugin add dsh-billing-tui`
- Submitted an inclusion PR to awesome-deepseek-harness under Dashboard & Session UX (#413; awaiting maintainer review)
- Introduced the plugin in the DeepSeek Harness repository's “Show Your Plugins!” Discussion (#3307)

## Technical notes

- Subscribes to session events and accumulates input, output, cache-hit, and reasoning tokens; forked sessions inherit their parent usage
- Determines peak and off-peak periods in Asia/Shanghai and charges supported DeepSeek models against the official price table
- Provides `/billing`, `show_billing`, and `check_pricing_period`, while deduplicating unchanged snapshots to prevent stacked receipts
