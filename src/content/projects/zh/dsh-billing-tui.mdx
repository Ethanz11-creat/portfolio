## 一句话定位

一个面向 **DeepSeek Harness（DSH）** 的计费插件：按 DeepSeek 官方峰谷定价计算当前会话费用，在 TUI 状态栏实时显示累计费用，并通过 `/billing` 生成一张鲸鱼 ASCII 账单小票；同时提供 Web UI。

## 做什么

- **实时 token 监控**：监听 DS Harness 的 token 用量，按 **DeepSeek 官方峰谷分时定价**（高峰/低谷费率不同）换算成费用。
- **TUI 状态栏集成**：费用累计值直接显示在 DSH 的 TUI 状态栏，编码时随时可见、心里有数。
- **账单小票**：输入 `/billing` 输出一张格式化的鲸鱼 ASCII 小票——把"我花了多少钱"变成可留存、可分享的视觉凭证。
- **Web UI**：同一套计费逻辑再暴露一层网页，满足非终端场景查看。

## 怎么用 AI 做的

这是我自己 vibe coding 的产物，也是 **LLM tool/API 数字接口设计**的练习：

- 面向 DSH 的插件开发，遵循其 `dsh-plugin` 的接口约定，做好生命周期与事件钩子。
- 按官方定价表建模峰谷计费逻辑，处理分时费率切换与累计统计。
