## One-liner

A billing plugin for **DeepSeek Harness (DSH)**: compute the live session cost using DeepSeek's official peak/off-peak pricing, show the running total in the TUI status bar, and print a whale ASCII receipt via `/billing`; it also ships a Web UI.

## What it does

- **Live token monitoring**: listens to DS Harness token usage and converts it into cost using **DeepSeek's official peak/off-peak pricing** (different rates for high/low load periods).
- **TUI status-bar integration**: the running cost is shown directly in DSH's TUI status bar — you always know the tab while coding.
- **Receipt**: type `/billing` to print a formatted whale ASCII receipt — turning "how much did I spend" into a storable, shareable visual artifact.
- **Web UI**: the same billing logic exposed as a web page for non-terminal scenarios.
